# CalAgent AI — Frontend Application

This directory contains the Next.js 16 user interface for **CalAgent AI**.

For full project documentation, architecture overview, environment setup, and backend instructions, please refer to the main repository [README.md](../README.md).

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Set Up Environment Variables
Ensure `.env` exists in this directory (refer to `.env.example`):
```ini
NEXT_PUBLIC_DESCOPE_PROJECT_ID=your_descope_project_id
NEXT_PUBLIC_API_URL=http://localhost:4000
```

### 3. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
